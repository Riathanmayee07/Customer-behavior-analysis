# Customer Shopping Behavior Analytics

An end-to-end data analytics project that analyzes customer shopping behavior using **Python, PostgreSQL, SQL, and Power BI**. The project covers data preprocessing, exploratory data analysis (EDA), SQL-based business analysis, and interactive dashboard development.

---

## 📌 Overview

This project transforms raw customer shopping data into actionable business insights through:

* Data cleaning & preprocessing
* Exploratory Data Analysis (EDA)
* Feature engineering
* PostgreSQL database integration
* SQL business queries
* Interactive Power BI dashboard

---

## 📂 Dataset

Customer shopping dataset containing demographic, product, purchase, payment, shipping, and subscription information.

---

## 🛠 Tech Stack

* Python
* Jupyter Notebook
* Pandas
* PostgreSQL
* SQL
* Power BI

---

## 🔄 Workflow

1. Load dataset in Python
2. Clean and preprocess data
3. Perform EDA and feature engineering
4. Import data into PostgreSQL
5. Execute SQL queries for business insights
6. Build interactive Power BI dashboard
7. Generate report and presentation
